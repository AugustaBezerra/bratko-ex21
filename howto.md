# HOWTO

## Requisitos

- SWI-Prolog instalado

Download:
https://www.swi-prolog.org/download/stable

---

## Executando o exercício 21.1

Abrir o SWI-Prolog:

```bash
swipl
```

Carregar o arquivo:

```prolog
[ex21_1].
```

Teste:

```prolog
has_daughter(tom).
```

Resultado esperado:

```prolog
true.
```

Outro teste:

```prolog
has_daughter(ann).
```

Resultado esperado:

```prolog
false.
```
